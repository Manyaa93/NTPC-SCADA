# Thermal Power Plant Fault Detection & Diagnosis

### Machine Learning-Based Anomaly Detection for Dynamic Industrial Systems

## Overview

This project focuses on developing a machine learning-based fault detection and diagnosis system for thermal power plants using operational data.

Thermal power plants operate through complex, interconnected systems where abnormal operating conditions can affect efficiency, reliability, and overall plant performance. The objective of this project was to build a data-driven pipeline capable of identifying unusual operating patterns and distinguishing normal system behaviour from potential faults.

The project applies advanced pattern recognition and machine learning techniques to support predictive monitoring and early identification of operational abnormalities.

## Objectives

- Develop an end-to-end machine learning pipeline for fault detection and diagnosis.
- Analyse thermal power plant operational data to identify abnormal patterns.
- Apply pattern recognition techniques to distinguish normal and abnormal operating conditions.
- Evaluate machine learning models for their ability to identify potential faults.
- Explore data-driven approaches to monitoring dynamic industrial systems.

## Key Features

- Data Processing: Preparation and analysis of operational data for machine learning applications.
- Pattern Recognition: Identification of patterns and deviations in system behaviour.
- Fault Detection: Detection of abnormal operating conditions using machine learning.
- Model Evaluation: Assessment of model performance in identifying potential faults.
- Industrial Application: Application of machine learning to thermal power plant monitoring.

## Methodology

The project follows a structured machine learning workflow:

1. **Data Collection:** Working with operational data from thermal power plant systems.
2. **Data Preprocessing:** Preparing the dataset for analysis and model development.
3. **Exploratory Data Analysis:** Understanding operational patterns and identifying potential anomalies.
4. **Model Development:** Building machine learning models for fault detection and diagnosis.
5. **Model Evaluation:** Evaluating model performance in identifying abnormal operating conditions.
6. **Fault Identification:** Using model predictions
